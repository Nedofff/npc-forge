# Кузница NPC

**Генератор случайных NPC для D&D и других фэнтези-настолок.** Полностью на русском, без регистрации, сервера, фреймворков и зависимостей.

![Лицензия](https://img.shields.io/badge/license-MIT-c9a76c) ![Static](https://img.shields.io/badge/deploy-GitHub%20Pages-2c5d50)

## Что умеет

- Имена и фамилии для 8 народов, профессии, места встречи, возраст, детали внешности.
- Темперамент, отношение к приключенцам, актуальная проблема, мотив, страх и принцип.
- Голос, темп, манера речи, включая шепелявость, картавость, змеиное шипение и другие особенности.
- Пример первой реплики NPC (часть особенностей отражается непосредственно в тексте).
- Секрет, ресурс и слух как зацепки для приключения.
- **5 реакций на действия игроков:** угрозы, подкуп, лесть, просьбы и разоблачение.
- Переброс отдельных блоков и закрепление удачных черт при генерации нового NPC.
- Сохранение NPC и история в `localStorage`, заметки мастера.
- Копирование в Obsidian как Markdown, скачивание отдельных `.md`.
- Экспорт/импорт JSON-базы для резервных копий и переноса между компьютерами.
- Адаптивная версия для телефонов и планшетов.

## Публикация на GitHub Pages

1. Создай публичный репозиторий на GitHub, например `npc-forge`.
2. Файлы приложения (`index.html`, `style.css`, `data.js`, `app.js`) уже находятся в корне репозитория.
3. Открой `Settings → Pages`.
4. В **Build and deployment** выбери `Deploy from a branch`, затем `main` и `/ (root)` и нажми `Save`.
5. Открой адрес вида `https://ТВОЙ-ЛОГИН.github.io/npc-forge/` после публикации.

Никаких `npm install`, сборки и специальных GitHub Actions не требуется.

## Локальный запуск

Просто открой `index.html` в браузере. Можно также запустить локальный сервер:

```sh
python -m http.server 8000
```

И открыть `http://localhost:8000`.

## Как изменить генератор

Все словари данных лежат в `data.js` (в текущем `index.html` также есть встроенная копия данных). Можно дописать имена, профессии, особенности речи и таблицы тайн/слухов. Логика генерации и сохранения — в `app.js`, оформление — в `style.css`.

Фильтры влияют на **следующую** генерацию (или переброс соответствующей части). Закреплённые блоки остаются прежними, даже если поменять фильтры. При перебросе «Кто это» профессия и место сохраняются; если меняется народ, внешность тоже обновляется, пока не закреплена.

## Важно

**Сохранения локальные:** они хранятся в конкретном браузере/профиле, не на GitHub. Очистка данных сайта, приватный режим или другой компьютер могут привести к потере базы. Делай «Экспорт базы», если персонажи важные.

Содержание создаётся случайной комбинацией текстовых шаблонов — приложение **не использует ИИ**. Поэтому иногда возможны неожиданные или внутренне противоречивые сочетания. Их можно перебросить по блокам.

Проект фанатский, неофициальный и не связан с правообладателями Dungeons & Dragons.
